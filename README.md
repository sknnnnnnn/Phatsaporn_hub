# My RU — Perfect Layout Pass

- หน้าแรกใช้พื้นที่เต็มขึ้นและเน้นข้อมูลนักศึกษาเท่านั้น
- ตารางเรียนคำนวณตำแหน่ง top/left ตามวันและเวลาจริง แก้กล่องหลุดแถวและแยกวิชาที่เหลื่อมกัน
- ชีวิตมหาลัยปรับเป็น Scrapbook และเพิ่มรูปได้สูงสุด 6 รูปต่อความทรงจำ
- รูปถูกย่อก่อนบันทึกลงเครื่องเพื่อลดพื้นที่
- Sync UI ไม่ให้กรอก endpoint ปลอมอีกต่อไป: ถ้ายังไม่มี Server Connector จะแจ้งสถานะตรง ๆ และยังใช้ Local Save ได้
- รองรับ Desktop / iPad / Mobile

หมายเหตุ: การ Sync e-Service / On Demand จริงยังต้อง deploy Server Connector ก่อน เพราะไม่ควรฝังรหัสผ่าน RU ใน GitHub Pages
